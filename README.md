# 3D 台灣地震時空圖譜

用 3D 方式看台灣附近的地震震源分布（1935–2026）。

網站：https://jgejoseph.github.io/tw-quake3d/

> 本站為個人獨立製作的教育用視覺化，**非官方服務**，不提供即時地震資訊或預警。即時資訊請見[中央氣象署地震測報中心](https://scweb.cwa.gov.tw/)。

## 功能

- 3D 地形（含海底地形）與震源位置；點的顏色代表深度（也可改成依年份、色弱友善配色），點的大小代表規模
- 年份時間軸：逐年累積播放、只看單一年份、倍速、循環播放；規模 7 以上播放時特別標示
- 最小規模滑桿、顯示全部資料（1935 起，含規模 3 以下）、規模最大前 10 名
- 圖層：縣市名稱、縣市邊界、板塊與隱沒板塊、活動斷層（示意位置）、深度尺
- 地形透明度、掀開地形、原始高度（地形不放大）
- 預設視角：台灣鳥瞰、地底剖面（由南往北）、琉球隱沒帶（由東往西）
- 點選地震或斷層會顯示資料卡；「地震小知識」附官方資料連結
- 支援手機

為方便觀察，地形高度有放大（陸地 ×15、海底 ×5），震源深度沒有放大。

## 資料來源

- **地震目錄**（`data/earthquakes.csv`，共 933,305 筆，經本站重新整理、篩選、合併並轉換格式）：
  - 1935-02-10 至 2025-03-01 06:36：交通部中央氣象署地震測報中心「地震活動彙整」網頁（https://scweb.cwa.gov.tw/zh-tw/history ，取得日期 2026-11-10），依中央氣象署[政府網站資料開放宣告](https://scweb.cwa.gov.tw/zh-tw/page/intro/79)利用（查核日期 2026-11-11）。
  - 2025-03-01 06:36 之後至 2026-09-30（僅規模 3 以上，共 3,498 筆）：提供機關／交通部中央氣象署 地震目錄-本年度地震目錄（E-A0073-001）、地震目錄-歷史地震目錄（E-A0073-002）（[氣象資料開放平臺](https://opendata.cwa.gov.tw/)，取得日期 2026-11-11）。此開放資料依政府資料開放授權條款 (Open Government Data License) 進行公眾釋出，使用者於遵守本條款各項規定之前提下，得利用之。授權依據：[氣象資料開放平臺使用規範](https://opendata.cwa.gov.tw/about/rules)、[政府資料開放授權條款](https://data.gov.tw/license)（查核日期 2026-11-11）。
  - 本站資料可能與氣象署公布內容有差異，正式資料以中央氣象署公布者為準；本站內容未經中央氣象署審閱，不代表其建議、認可或贊同。

- **活動斷層**：經濟部地質調查及礦業管理中心 2021 [活動斷層分布圖](https://data.gov.tw/dataset/6697)（WMS 圖層「1/25,000_臺灣活動斷層分布圖(含名稱)_2021」），本站依其影像描繪簡化，**僅為示意位置，非精確位置**（`data/faults.json`）。

以上縣市界與活動斷層資料，依政府資料開放授權條款 (Open Government Data License) 進行公眾釋出，使用者於遵守本條款各項規定之前提下，得利用之。政府資料開放授權條款：https://data.gov.tw/license

- **隱沒板塊**：USGS Slab2（Hayes et al., 2018, doi:[10.5066/F7PV6JNV](https://doi.org/10.5066/F7PV6JNV)），公有領域。

## 資料範圍與限制

- 範圍：1935-02-10 至 2026-09-30；北緯 20.05–26.0 度、東經 118.29–123.96 度。資料最東只到東經約 123.96 度，更東邊的地震不在本站資料中。
- 網站預設只顯示 1990 年以後、規模 3 以上的地震（75,147 筆）；勾選「顯示全部資料」才會顯示全部 933,305 筆。
- 早年測站少，多半只記到規模 4 以上，不同年代的數量不能直接比較。1993 年 11 月以前每月多為數百筆（1993 年 10 月只有 194 筆），之後增加到每月約一千筆以上，這是原始資料本來的樣子。
- 早年深度常記成整數或固定值：1935–1972 年約 98% 是整數深度，其中約 43% 記為 0 公里；1973–1990 年也有不少記為 10 公里。畫面上一層層的橫條是原始資料本來的樣子。
- 琉球隱沒帶附近（本站初步比對，非正式研究）：取東經 122–124.5 度、北緯 23–25.5 度，1990 年以後、規模 3 以上、深度 50 公里以上，且位於 Slab2 範圍內的氣象署地震，約 6,400 筆。方法：以 Slab2 原始 0.05 度深度網格，用雙線性內插求出每個震央的板塊上緣深度，計算「震源深度 − 板塊深度」；並在同一經度上找出 Slab2 到達同樣深度的緯度，比較南北位置。結果：99.5% 的震源落在 Slab2 板塊上緣面下方，深度差中位數約 62 公里（換算成垂直於板塊面的距離約 56 公里），而且越深差越大（震源深度 50–100 公里約 45 公里，200 公里以上約 144 公里）；同深度處震源約偏南 0.7 度（約 76 公里），因此兩者形狀並不一致。Slab2 在這些震央位置標示的板塊深度不確定性（unc 網格，深度估計的標準差）中位數約 31 公里，深度差約為其 2 倍。本站只抽查過 Slab2 轉檔（與官方等深線比對一處相符），不能完全排除本站資料處理或繪圖的誤差；氣象署的震源定位誤差也未評估。偏差原因尚未查證，兩者並列僅供示意。
- 地形是約 1.85 公里一格的全球模型，而且高度有放大；部分海域地震會看起來浮在海床上方。
- 2025-03-01 06:36 之後只有規模 3 以上，資料只到 2026-09-30，不是即時資料。
